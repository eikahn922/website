Dogwood Brands is a boutique private equity firm that acquires and operates scalable consumer and franchise businesses. As a software engineering intern, I built internal tools for operations, vendor research, and recruiting.

Ezra, an AI Operations Platform

I helped build Ezra, an operational intelligence platform for multi-unit franchise businesses. It connects to the POS systems those businesses already run on, including Zenoti, Square, and Stripe, ingests their transaction data, and normalizes records from each into a single schema so locations on different systems can be compared directly.

On top of that normalized layer, behavioral anomaly detection flags irregularities in cashier activity, tip patterns, and transactions, then routes each alert to the operator responsible for that location along with the context needed to act on it. The same pipeline feeds modules for labor scheduling and overtime, revenue tracking, and customer retention, surfaced together in an executive view across units.

I led implementation work with an international team based in Pakistan and India, coordinating responsibilities, reviewing progress across time zones, and connecting technical decisions back to what operators actually needed on the floor.

KPI Reporting Across 60+ Locations

I automated daily performance reporting for more than 60 Supercuts locations using Python and advanced Excel workflows. The system standardized recurring analysis, reduced manual reporting work, and made operating trends easier for the team to review.

Vendor Website Scraper

I developed a Python workflow that enriches incomplete vendor spreadsheets using information from public company websites. It accepts PDF, Excel, and CSV inputs, preserves the original source, and produces a review file containing source URLs, confidence ratings, statuses, and notes for every generated value. This made product and service comparisons faster while keeping the results traceable for human review.
