KPI Reporting Across 60+ Locations

I automated daily performance reporting for more than 60 Supercuts locations using Python and advanced Excel workflows. The system standardized recurring analysis, reduced manual reporting work, and made operating trends easier for the team to review.

Vendor Website Scraper

I developed a Python workflow that enriches incomplete vendor spreadsheets using information from public company websites. It accepts PDF, Excel, and CSV inputs, preserves the original source, and produces a review file containing source URLs, confidence ratings, statuses, and notes for every generated value. This made product and service comparisons faster while keeping the results traceable for human review.
